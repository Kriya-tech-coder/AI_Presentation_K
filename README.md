Artificial Intelligence — Interactive Presentation

An interactive presentation exploring Artificial Intelligence through a futuristic design and animated 3D particle visuals.

Features

- Animated introduction screen
- Futuristic scanner transition
- AI history and basic concepts
- Types of Artificial Intelligence
- Advantages and disadvantages of AI
- Interactive Next and Back buttons
- Keyboard navigation
- Mobile swipe navigation
- Fullscreen mode
- Animated 3D visuals using Three.js

Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js

Project Files

- "index.html" — Main presentation page
- "style.css" — Styling and animations
- "script.js" — Presentation logic and 3D effects

How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open "index.html" using Live Server.
4. Keep an internet connection enabled for the external Three.js library and Google Fonts.
